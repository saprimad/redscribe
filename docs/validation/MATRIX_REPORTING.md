# Model-major reporting
Exports model_summary.csv (all attempted and common completed cohorts), recording_results.csv (participant IDs, counts and timing), efficiency_summary.csv (mean, median and duration-weighted RTF). Rates are fractions. Failed and missing rows are not zero scores. RTF includes runner overhead, excludes loading and warm-up. Counts use RapidFuzz alignment. Exports are derived from checkpoint metadata, not independent artifact verification. Excel, figures, resource summaries and inferential statistics remain pending. Reporting schema change rejects older checkpoints.
