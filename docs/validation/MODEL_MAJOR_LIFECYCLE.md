# Model-major lifecycle protocol (experimental)

One session per model with pending recordings. Optional warm-up must use a separately approved non-study recording, never scored. Session loading and warm-up durations are shared session metadata, not additive per-recording costs. Inference duration excludes checkpoint persistence. Session identifiers distinguish restarts. The scheduler accepts a verified-skip callback; it does not itself verify or persist artifacts. A future integration must validate reference, prediction, configuration and dataset hashes before skipping. A failed inference invalidates the current session. Cleanup failures stop execution rather than silently loading another model. GPU memory release, actual adapter reuse, full-length scoring and GUI integration remain unvalidated. Existing normal transcription is unchanged.
