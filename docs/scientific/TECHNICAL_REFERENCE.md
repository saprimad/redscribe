# Technical reference

Revision inspected: `24cafc03effd13d88f61b2167216cf358d90ce18`. This reference follows local interfaces invoked by the desktop. Python functions below are implementation interfaces whose contracts can change between releases. The [architecture atlas](figures/README.md) maps their data flows.

| Component | Input and precondition | Result or failure boundary |
|---|---|---|
| [Desktop transcription](../../redscribe_gpu.py), `RedScribeApp._run_whisper` | A recording, selected model and transcription settings from the desktop. Preflight checks precede model preparation. | Loads the selected engine and optionally obtains speaker turns. A failed diarisation call can yield an empty turn list and ASR continues. Saves Excel before Word. A partial export can therefore leave a valid spreadsheet. |
| [Model registry](../../model_options.py), `preflight_model` | Stable model key and optional language. Extra models require compatible CUDA and runtime imports. | Preflight can reject language/device/runtime before weights load. Successful import alone gives no inference evidence. |
| [Reference approval](../../redscribe/benchmark/benchmark_reference.py), `approve_reference` | Existing DOCX, non-blank scoring text, output directory and affirmative reviewer acknowledgement. Optional preview digest must match when supplied. | Writes uniquely named UTF-8 text and a schema-2 JSON manifest. A supplied non-empty verification dictionary must satisfy all four checks. Otherwise scoring scope is unspecified. |
| [Dataset](../../redscribe/benchmark/benchmark_dataset.py), `approve_dataset`, `verify_dataset` | Each pair supplies participant ID, audio and an approved reference manifest. Pair approval requires acknowledgement. | Rejects duplicate IDs after case folding, duplicate audio bytes and duplicate source DOCX bytes. Recomputes each pair at verification and requires equality with stored rows. |
| [Desktop experiment](../../redscribe/ui/benchmark_ui.py), `BenchmarkWindow.open_full_matrix` | Current settings must equal the reviewed configuration. | Creates a new experiment with one row and opens the [matrix UI](../../redscribe/ui/benchmark_matrix_ui.py). Multi-pair capability exists in the underlying runner. |
| [Structured runner](../../redscribe/benchmark/benchmark_structured_output.py), `run_structured_batch` | Approved dataset path, model list and an admissible output root. Optional keyword arguments reach the private runner. | Validates the root, acquires a private output lock, runs the matrix and publishes the filtered package. Exceptions can interrupt report generation after predictions have been saved. |
| [Batch execution](../../redscribe/benchmark/benchmark_model_major_batch.py), `_run_model_major_batch` | Distinct models, verified dataset, positive decoded durations up to 7,200 s inclusive. Native duration is measured after decoding at 16 kHz. | Binds requested conditions and provenance in the matrix identity. Records raw predictions, hashes, scores and cell status. Injected sessions are distinguished in the identity. |
| [Worker](../../redscribe/benchmark/benchmark_isolated_session.py), `IsolatedSession` | Model key, language and private log destination. Parent starts a spawned child and communicates via a pipe. | Child preflights the selected key, loads the local or Whisper wrapper and returns prediction text. The parent persists scientific state. Worker exit and ASR completion are distinct observations. |
| [Checkpoint](../../redscribe/benchmark/benchmark_matrix_checkpoint.py), `MatrixCheckpoint.record` | Known model/recording cell in a matching schema-1 identity. | Writes a temporary file, flushes and fsyncs, then replaces the matrix. A failed save restores the former in-memory state and removes the temporary file. Guarantees depend on local filesystem semantics. |
| [Measurement](../../redscribe/benchmark/benchmark_fast_metrics.py), `raw_wer_fast`, `raw_cer_fast` | Approved scoring string and hypothesis string. | Returns edit counts against reference units from the RapidFuzz edit sequence. The caller stores rates as fractions. See [measurement conventions](BENCHMARK_METHODOLOGY.md). |
| [Publication](../../redscribe/benchmark/benchmark_structured_output.py), `_publish`, `verify_publication` | Raw matrix state. Result fields and PDF metadata pass through separate selectors. | Installs PDF, workbook and supporting material, then checks each manifest-listed digest. Original paths, logs and unfiltered predictions belong in restricted storage. A verified digest only identifies a file version. |

## Operating and recovery boundaries

For a new run, use the reviewed desktop configuration, approve the reference, pair the recording and select the target models. Record the exact code revision, package versions, checkpoint revisions and decision about warm-up. Keep the source recordings, manifests and free-text diagnostics in restricted storage. The [illustrated guide](../user-guide/README.md) shows the user-facing controls.

To continue an interrupted matrix, retain the existing experiment directory and original approved inputs. The scheduler validates identity, recomputes saved scores and checks prediction digests before reusing cells. A changed identity requires a separate experiment. A report regeneration using saved observations is a reporting operation. A fresh run on independently frozen inputs is required to measure repeatability. See the [implementation claims](CLAIMS.md) and [requirements and validation matrix](REQUIREMENTS_MATRIX.md).
