# Paired statistical analysis protocol and numerical revalidation

## Proposed analysis for the 25-recording experiment

**Status: proposed methodology, subject to researcher and supervisor approval before the official experiment.** Seven models applied to 25 recordings yield up to 175 observations in 25 matched blocks. Each block contains the same reference and audio for every model. Register the seven model revisions, scoring engine, verbatim conventions, random seeds, timing policy, recording eligibility, retry rule and intended contrasts before collecting outcomes. Disclose the prior P1 results if the same recording is included. Analyse all eligible recordings as specified and repeat descriptively with that previously viewed block omitted.

**Primary outcome and estimand.** Compute the raw WER for each recording as specified in the [benchmark methodology](BENCHMARK_METHODOLOGY.md). The primary descriptive contrast is the difference in equally weighted recording-level mean WER in percentage points, model A minus model B. A negative difference favours A. Report pooled corpus WER alongside it to expose the influence of reference length. CER is secondary. RTF measures efficiency. Use all common scored blocks for accuracy, then identify the common timed subset separately. Specify how an independently discovered coverage failure affects eligibility before unblinding the official results. Keep a record of all attempted observations.

**Description.** For each model provide valid n, attempted n, completion rate, failure reasons, S/D/I totals, denominators and corpus and macro rates. Summarise recording-level WER, CER, inference time and RTF with mean, sample standard deviation, median, quartiles, minimum and maximum. Define quartiles by linear interpolation at index (n−1)p. Retain rates exceeding 100%. Plot paired recording-level differences and reference lengths. Record missing values as unavailable. Present all-attempted results and all-seven-complete results side by side. Provide a sensitivity table for each pair using all blocks scored by that pair. Compare the duration and reference length of included and excluded recordings. Differential failures can select easier recordings and change the apparent ranking.

**Dependence and uncertainty.** The resampling unit is the entire recording vector across models. For 95% pointwise percentile intervals for means, mean differences and corpus-rate differences, draw n complete blocks with replacement 10,000 times using a documented generator, seed and software version. Recalculate paired differences or ratios of pooled counts within each replicate. Report the 2.5th and 97.5th percentiles and check sensitivity to influential blocks. These intervals are descriptive and pointwise. In particular, they do not by themselves control error over 21 contrasts. Small samples and narrow recruitment can limit coverage and generalisability. Verify whether speakers recur across interviews. A common interviewer conditions all conclusions on that interviewer. Where dependence across blocks prevents an independent-recording interpretation, use independent participant/session clusters if enough exist, or limit reporting to the observed corpus. Never bootstrap individual words, model rows or chunks as independent interviews.

**Rank-based comparisons.** Predefine a two-sided familywise threshold of 0.05 for all 21 unique WER pairs. Report a tie-corrected Friedman omnibus statistic on complete blocks with mean within-block ranks. Its null concerns the model effects on ranks and its test depends on independent blocks and exchangeability under the null. For sparse or heavily tied blocks use a within-block permutation reference only when model labels are exchangeable under the stated null. Record the generator, permutations, seed and Monte Carlo error. With k=7 models, report Kendall's W = Q/[n(k−1)], using the tie-corrected Q. If every block ties throughout, W and inference carry no discriminating information. These ranks address a different question from equality of the mean WER contrast.

If the omnibus rejects, perform the prespecified pairwise tests with Holm correction across all 21. Report raw and adjusted p-values, effect direction, number of non-zero pairs and percentage-point contrasts regardless of significance. Wilcoxon signed-rank inference requires independent paired differences plausibly symmetric under a location model. Use unrounded rates, remove exact zero differences, assign midranks to tied absolute differences and use a conditional signed-rank distribution supporting ties. Report matched-pairs rank-biserial effect (sum of positive minus negative ranks divided by their total), with direction defined by A minus B. For implausible symmetry, use the two-sided paired sign test for non-zero differences and report win/loss/tie counts. With no non-zero differences report ties only and reserve the family slot conservatively at p=1. A sign test measures direction, with reduced sensitivity to magnitude. Avoid selecting a test based on whichever produces a smaller p-value. Treat CER, timing and resource contrasts as exploratory descriptions in this protocol. No secondary confirmatory families have been authorised.

**Efficiency and interpretation.** Compute per-recording RTF and aggregate inference seconds divided by aggregate audio seconds. Report loading once per timed session. Keep session-level loading and system-wide sampled peaks distinct from independent recording observations. On the same valid jointly timed cohort display corpus WER against aggregate RTF and identify descriptive non-dominated candidates only when no other candidate is at least as good on both outcomes and strictly better on one. Equal points may coexist. Coverage, fixed scheduling order, warm-up, caching, background load and hardware limit speed comparisons. Restrict inferential statements to the sampled domain. The P1 illustration supplies no estimate of between-recording variability.

Methodological references: R Core Team, [Friedman rank sum test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/friedman.test.html), [paired signed-rank assumptions](https://search.r-project.org/R/refmans/stats/help/wilcox.test.html), [multiple testing adjustments](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html).
