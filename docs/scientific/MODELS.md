The first seven rows form the default benchmark set. The last four use the multilingual checkpoints. The Whisper repository provides the size table, tokenizer language codes and a general MIT statement. The installed Faster-Whisper version determines the mapping from the six short keys to converted repositories. Its download helper accepts a model name, whereas RedScribe supplies five complete repository IDs for the extra models. Each model and conversion retains its own terms alongside the software and dependency licences. A card label alone cannot resolve conflicting declarations or establish permission to redistribute weights. ## Inference routes and limitations

| Keys | Architecture and implementation | Effective structured run policy | Interpretation limit |
|---|---|---|---|
| large-v3, turbo, medium, small, base, tiny | Whisper encoder–decoder with Faster-Whisper / CTranslate2 | Strict CUDA FP16, language argument defaults to ms, transcription task, beam size 5, previous text conditioning on, VAD off. Joins non-empty native segment text | Native segmentation differs from the local adapter schedule. Standard desktop loading can fall back to CPU INT8 |
| Mesolitica Whisper v3, BuzzASR Malay | Whisper encoder–decoder with Transformers | CUDA FP16, explicit attention mask, five beams, up to 440 new tokens per chunk, timestamps disabled. Mesolitica uses the transcription task. Buzz defaults to Malay | Fixed windows provide approximate timing. Mesolitica's special precise-timestamp task is outside this route |
| Mesolitica XLS-R 300M | wav2vec 2.0 / XLS-R encoder and CTC head | CUDA FP16, finite-logit check, framewise argmax followed by processor decoding. Uses the mixed vocabulary | Malay configuration does not install a monolingual vocabulary. The upstream optional language-model decoding results use a different pipeline |
| Meta MMS 1B (Malay) | wav2vec 2.0 with language-specific adapter and CTC head | CUDA FP16, verify zlm vocabulary entry, set target language, load adapter, check finite logits and decode argmax | Selection fixes one adapter throughout the recording, including code-switched speech |
| Qwen3-ASR 1.7B | Qwen audio-conditioned generative recogniser via qwen_asr | CUDA device 0, FP16, inference batch size 1, up to 448 generated tokens. RedScribe maps ms/en to Malay/English and reads the first returned text | Generation controls inherited from the installed package need to be recorded. No separate forced-aligner invocation |

The five extra models receive mono decoded audio at 16 kHz in windows of at most 30 seconds on the structured route. All runs require direct runtime verification of input coverage, device, precision, effective settings and completion. A capped decoder may truncate long outputs. Successful decoding alone cannot establish completeness. The local desktop adapter may split at diarisation turns. Benchmark settings exclude this dependency.

For all eleven selections, an immutable experiment revision is **not independently verified**. The CTranslate2 loader asks for a cached/downloaded snapshot and attempts to record its revision. Other loading calls do not supply a revision argument and try to recover the model configuration commit. Preserve the resolved repository ID, exact commit, local file hashes for weights, tokenizer, processor and adapter, library versions and effective decoding configuration in restricted experiment records before comparing repeat runs. Pinning a Python dependency does not identify model artefacts. Upstream evaluations used different speech and scoring protocols and cannot establish accuracy for the intended interviews. The historical one-recording run covers the seven core models only.
